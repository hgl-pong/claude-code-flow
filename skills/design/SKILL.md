# Design

Select the smallest design workflow that matches the request.

## Workflow

1. Classify the mode from user intent and artifacts.
2. Read the matching reference.
3. Produce the requested artifact: critique, spec, audit, copy, or UI direction.
4. Call out assumptions, constraints, and implementation implications.

## Modes

| Mode | Use for | Reference |
|---|---|---|
| critique | design/mockup/UI feedback | `references/design-critique.md` |
| handoff | developer-ready specs | `references/design-handoff.md` |
| system | tokens/components/consistency | `references/design-system.md` |
| a11y | WCAG/accessibility audit | `references/accessibility-review.md` |
| copy | labels/errors/empty states | `references/ux-copy.md` |
| ui-design | create UI direction/spec | `references/ui-design.md` |

## Output

- Mode
- Key findings or design direction
- Concrete recommendations
- Open questions / implementation notes
